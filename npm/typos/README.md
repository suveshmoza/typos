# @crate-ci/typos

> Source code spell checker

Finds and corrects spelling mistakes among source code.

## Install

```console
$ npm install -D @crate-ci/typos
```

## Usage

```console
$ npx typos
$ npx typos --write-changes
```

Or from an npm script:

```json
{
  "scripts": {
    "spellcheck": "typos"
  }
}
```

See the [project README](https://github.com/crate-ci/typos#typos) for configuration and integrations.
